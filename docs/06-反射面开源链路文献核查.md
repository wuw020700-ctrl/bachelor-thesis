# 反射面天线开源链路 · 文献核查

日期：2026-11-04

## 结论

**不存在。** 公开文献里没有一篇把 openEMS、自研 GO/PO、开源有限元串成「馈源 → 反射面 → 面板变形 → 增益损失」的完整链路。

检索边界要说清楚：OpenAIRE 与 OpenAlex 的题录层对 `openEMS physical optics`、`openEMS reflector antenna`、`openEMS Cassegrain`、`openEMS horn reflector` 全部返回 0 条；openEMS 工具论文（DOI 10.1002/jnm.1875）的 54 篇被引文献逐条看过，用途全在贴片、MRI 线圈、光子晶体、太赫兹波导、FSS，**没有一篇**碰反射面或 PO 混合。

所以「没有」是指**索引范围内没有**。非索引期刊、学位论文、会议 poster 不能排除。

另一条独立核过的：FEniCSx / CalculiX / deal.II 做「天线结构变形 → 电磁退化」同样零命中。FEniCS 做电磁本身有（Otto et al., IEEE APM 2012, 10.1109/MAP.2012.6309184；FEniCSx 版 ICTON 2024, 10.1109/ICTON62926.2024.10647823），做「电磁-热-结构」顺序耦合也有，但对象是电机（Eng. Res. Express 2026, 10.1088/2631-8695/ae7d89，里面明确写了 reproducibility；Comput. Mech. 2026, 10.1007/s00466-026-02791-w）。这两篇是 FEniCSx 路线最近的技术先例，只是应用域不对。

## 对论文的用法

1. **验证范式照 Du 2016**：全波 → PO → 实测或理论对表，误差写清楚。它是唯一「全波 + PO + 实测」都齐的样板。
2. **方法依据引 Zhang 2013 和 Wang Wei 2023**：一个给 FEM→相位→远场积分的骨架，一个是双反射面 PO 相位误差。
3. **贡献定位放「开源实现 + 复现细节」**，不要放算法创新。算法层面每一段都有出处，串起来这条空着——空的那一处就是这篇论文能站的地方。
