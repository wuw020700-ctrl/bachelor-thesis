# 工具使用手册

面向本课题：**openEMS**（全波馈源） + **自研 GO/PO**（反射面高频近似） + **FEniCSx**（结构有限元）。

---

## 0. 先搞清楚工具分工

| 工具 | 干什么 | 跑在哪 | 语言 |
|---|---|---|---|
| **openEMS** | 馈源的全波仿真（FDTD），算近场/口径场 | WSL | Python（绑定）+ C++ 内核 |
| **自研 GO/PO** | 反射面的射线追踪与物理光学积分 | Windows | Python（我们自己的代码） |
| **FEniCSx** | 反射面面板的结构变形（有限元） | WSL | Python（dolfinx） |

为什么这么分：馈源尺寸小、结构复杂，必须全波；反射面是电大尺寸，
全波算不动，只能走高频近似。

## 2. openEMS

### 2.1 工作流

openEMS 不是图形软件，是**脚本驱动**的：

```
Python 脚本
   ├─ 1. 建 FDTD 引擎      openEMS(NrTS=..., EndCriteria=...)
   ├─ 2. 设激励与边界       SetGaussExcite / SetBoundaryCond
   ├─ 3. 建几何 + 网格      ContinuousStructure / AddMetal / AddLine / SmoothMeshLines
   ├─ 4. 加端口/激励        FDTD.AddLumpedPort(...)
   ├─ 5. 加近远场盒         FDTD.CreateNF2FFBox(...)
   ├─ 6. 跑                 FDTD.Run(path)
   └─ 7. 后处理             CalcPort / CalcNF2FF
```

### 2.5 API 速查

**FDTD 引擎**（`from openEMS import openEMS`）

| 调用 | 作用 |
|---|---|
| `openEMS(NrTS=..., EndCriteria=...)` | 建引擎；`NrTS` 最大步数，`EndCriteria` 收敛阈值 |
| `SetGaussExcite(f0, fc)` | 高斯脉冲激励，中心频率 f0、带宽 fc |
| `SetBoundaryCond(['PML_8']*6)` | 六个面都设 8 层 PML 吸收边界 |
| `SetCSX(csx)` | 绑定几何对象 |
| `AddLumpedPort(nr, Z, start, stop, dir, excite)` | **集总端口（注意在 FDTD 上，不在 CSX 上）** |
| `CreateNF2FFBox(name, opt_resolution=[..], frequency=[..])` | 近远场变换盒 |
| `Run(path, cleanup=True, verbose=0)` | 跑仿真 |

**几何**（`from CSXCAD import ContinuousStructure`）

| 调用 | 作用 |
|---|---|
| `CSX.AddMetal(name)` | 金属（PEC） |
| `CSX.AddMaterial(name, epsilon=..)` | 介质 |
| `CSX.AddProbe(name, type=..)` | 场探针 |
| `prop.AddCylinder(a, b, r)` | 圆柱 |
| `prop.AddBox(a, b)` | 长方体 |
| `mesh.AddLine('x', [...])` | 强制网格线 |
| `mesh.SmoothMeshLines('all', res, ratio)` | 自动加密到目标分辨率 |

### 2.6 踩过的坑（真实报错）

| 报错 | 原因 | 解决 |
|---|---|---|
| `'ContinuousStructure' object has no attribute 'AddLumpedPort'` | 端口挂在 **FDTD** 对象上，不在 CSX 上 | 用 `FDTD.AddLumpedPort(...)` |
| `CreateNF2FFBox: not enough lines in some direction` | 域太小 / 网格太稀，盒子放不下 | 加大域、加密网格，保证盒子落在网格内部 |
| `SetOptResolution: object of type 'float' has no len()` | `opt_resolution` 要长度 3 的序列 | 传 `[RES, RES, RES]` |
| `CalcVoltageIntegral: only a 1D/line integration is allowed` | 端口起止点同时在多个轴上变化 | 起止点**只沿一个轴变化** |
| `Prad = 0`、`Dmax = nan` | 天线是整根没留馈电间隙的圆柱 | 天线分两段，中间留 gap 放端口 |

## 3. FEniCSx

### 3.1 工作流

FEniCSx 是**弱形式**有限元库，写的是变分形式：

```
1. 建网格          mesh.create_unit_square / gmsh 导入
2. 建函数空间      fem.functionspace(mesh, ("Lagrange", 1))
3. 写弱形式        a(u,v) = L(v)   ← 用 UFL 表达式
4. 加边界条件      fem.dirichletbc
5. 求解            LinearProblem(a, L, bcs=[...]).solve()
6. 后处理          uh.x.array / 投影到别的空间 / 导出
```

### 3.2 第一个例子：Poisson

```bash
conda activate fenicsx
python ~/openems-tutorials/poisson_demo.py    # 见下面代码
```

```python
from mpi4py import MPI
from dolfinx import mesh, fem, default_scalar_type
from dolfinx.fem.petsc import LinearProblem
import ufl

# 1. 网格
m = mesh.create_unit_square(MPI.COMM_WORLD, 32, 32)

# 2. 函数空间
V = fem.functionspace(m, ("Lagrange", 1))

# 3. 边界条件（必须加！否则 Laplacian 奇异，解会漂移）
tdim = m.topology.dim
fdim = tdim - 1
m.topology.create_connectivity(fdim, tdim)
facets = mesh.exterior_facet_indices(m.topology)
dofs = fem.locate_dofs_topological(V, fdim, facets)
bc = fem.dirichletbc(default_scalar_type(0.0), dofs, V)

# 4. 弱形式：-Δu = 1
u, v = ufl.TrialFunction(V), ufl.TestFunction(V)
f = fem.Constant(m, default_scalar_type(1.0))
a = ufl.inner(ufl.grad(u), ufl.grad(v)) * ufl.dx
L = f * v * ufl.dx

# 5. 求解
problem = LinearProblem(a, L, bcs=[bc], petsc_options_prefix="poisson_",
                        petsc_options={"ksp_type": "cg", "pc_type": "jacobi"})
uh = problem.solve()

print(f"峰值 = {uh.x.array.max():.6f}  (理论 0.0736)")
```

我们的验证脚本：`work/verify_fenicsx.sh`，实测误差 **1.47e-05**。

### 3.3 API 速查

| 调用 | 作用 |
|---|---|
| `mesh.create_unit_square(comm, nx, ny)` | 单位正方形网格 |
| `mesh.create_box(comm, [x,y,z])` | 长方体网格 |
| `mesh.exterior_facet_indices(topology)` | 边界 facet |
| `fem.functionspace(mesh, ("Lagrange", 1))` | 标量函数空间 |
| `fem.functionspace(mesh, ("Lagrange", 1, (3,)))` | 矢量场（3 分量） |
| `fem.dirichletbc(value, dofs, V)` | Dirichlet 边界条件 |
| `fem.form(ufl_expr)` | 编译 UFL 表达式 |
| `fem.assemble_matrix(form)` | 装配矩阵 |
| `fem.assemble_vector(form)` | 装配向量 |
| `LinearProblem(a, L, bcs=[...]).solve()` | 一步求解 |
| `uh.x.array` | 取解向量 |

### 3.4 踩过的坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 解出 445095 这种离谱值 | **忘了加 Dirichlet 边界条件**，Laplacian 奇异 | `bcs=[bc]` 一定要传 |
| `ModuleNotFoundError: petsc4py` | Windows 装不上 | 用 WSL 的 conda 环境 |
| `Can not map ... to a basix type` | ffcx 与 ufl 版本不配对 | 用 conda 一起装，别单独 pip |

### 4.3 怎么用这几个模块

```python
import sys
sys.path.insert(0, r"C:\Users\ww\Documents\Codex\2026-10-09\ai\src")

from common.cassegrain import default_20lambda
from go_po.rays import trace_rays
from go_po.po import far_field_aperture
from go_po.feed import cos_power_pattern

# 几何
geo = default_20lambda(M=4.0)
geo.assert_consistency()           # 自检，不过会抛异常
print(geo.blocking_ratio)          # 遮挡比
print(geo.z_focus_far)             # 馈源位置

# 射线追踪
bundle = trace_rays(geo, n_radial=26, n_azimuth=72)
print(bundle.collimation_error())  # 准直误差，应 ~1e-15
print(bundle.path_length_ripple()) # 光程起伏，应 ~1e-14

# 远场
feed = cos_power_pattern(8.0)
theta = np.linspace(0, np.radians(10), 401)
pattern = far_field_aperture(geo.R, 2*np.pi, illum, theta)
```

### 4.4 改代码时注意

- **导入根是 `src/`**，所以是 `from common.cassegrain import ...`，不是 `from src.common...`
- **`L` 是自由设计参数**，不要用 `L = F/M`（那会得到 67% 遮挡）。
  默认 `L = M·F/(M+1)`，可用 `Cassegrain.with_blockage(0.05)` 按目标遮挡反解。
- **光程不变量是 `r1 + r2 - z_main`**，不是 `r1 + r2`。

## 5. 把三者串起来（本课题的完整链路）

```
   ┌──────────────────────────────────────────────────────┐
   │ ① openEMS（WSL）                                     │
   │    角锥喇叭馈源 -> FDTD -> NF2FF -> 馈源方向图 g(θ)   │
   └───────────────────────┬──────────────────────────────┘
                           │ g(θ)
                           ▼
   ┌──────────────────────────────────────────────────────┐
   │ ② 自研 GO/PO（Windows）                              │
   │    g(θ) -> 射线追踪 -> 口径场 -> PO 积分 -> 远场方向图 │
   └───────────────────────┬──────────────────────────────┘
                           │ 口径相位扰动 dphi = 2k·w
                           ▲
   ┌───────────────────────┴──────────────────────────────┐
   │ ③ FEniCSx（WSL）                                     │
   │    面板建模 -> 载荷 -> 位移场 w(x,y)                  │
   └──────────────────────────────────────────────────────┘
```

### 数据接口约定

| 环节 | 格式 | 说明 |
|---|---|---|
| ① → ② | `g(θ)` 数组或 HDF5 | 馈源归一化电压方向图 |
| ③ → ② | 位移场 `w(x,y)` 网格 | 建议 `.npz` 或 `.vtu` |
| ② 输出 | 方向图 `E(θ,φ)` | `.npz` |

## 6. 调试技巧

### openEMS

```python
FDTD.Run(path, cleanup=False, verbose=2)   # 保留中间文件，看详细日志
```

- 工作目录里的 `et`/`ht` 是时域场 dump，可以用 `h5py` 读
- 能量不下降 → 边界条件或时间步有问题
- 想在 MATLAB/Octave 里看模型：`addpath(...)`，见安装时输出的提示

### FEniCSx

```python
from dolfinx.io import XDMFFile, VTXWriter
with VTXWriter(mesh.comm, "out.bp", [uh]) as f:
    f.write(0.0)
```

然后用 `pyvista` 读 `.bp` 或转成 `.vtu` 画图。

### 自研代码

先跑自检再信结果：

```python
geo.assert_consistency()
assert bundle.collimation_error() < 1e-12
assert bundle.path_length_ripple() < 1e-10
```

这三个判据是我们代码的"体温计"，任何几何/法向错误都会立刻暴露。
