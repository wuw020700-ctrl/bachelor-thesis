## 1. [高] 口径幅度用 g/(r1+r2)，不满足双反射面的射线管能量守恒

**位置**：`src/antennasim/pipeline.py:56–69`，核心在 L60；同一份代码复制在
`examples/cassegrain_20lambda/m3_cassegrain.py:65`。

**问题**：把单抛物面的 `A = g(θ)/r` 直接搬到卡塞格伦，只是把 r 换成了总光程 r1+r2。

**依据**：口径平面功率守恒要求 `|E_a| = |g|·sqrt(dΩ/dA)`。本几何数值验到
`rho = 2·M·F·tan(θ/2)`（偏差 5e-15），于是 `dA/dΩ = F²M²/cos⁴(θ/2)`，
正确幅度是 `g(θ)·cos²(θ/2)/(M·F)`。

单抛物面时 `r = F/cos²(θ/2)`，所以 `g/r` 恰好等于这个式子——**原公式在单面上是对的**。
换到双反射面，等效扩散距离是 `M·F = 32λ`，不是 `r1+r2 ≈ 12.8→15.9λ`。
`feed.py:51–54` 的 docstring 说 "reflector conserves the ray-tube power"，这句在双反射面链路上不成立。

**影响**（同一套流程复算）：

| 量 | 代码 | 正确 |
|---|---|---|
| 口径边缘锥削 | −3.59 dB | −1.90 dB |
| 第一副瓣 | −19.60 dB | −18.58 dB |
| 第一零点深度 | −68 dB | −75 dB |
| 遮挡增益损失 | −0.538 dB | −0.490 dB |

**验证**：

```python
import numpy as np
from common.cassegrain import default_20lambda
from go_po.rays import _trace_one_direction
geo = default_20lambda()
th = np.linspace(1e-3, 0.309, 2001)
_, pm, _, r1, r2, ok = _trace_one_direction(geo, th, np.zeros_like(th))
rho = np.hypot(pm[:, 0], pm[:, 1])
print(np.max(np.abs(rho - 2 * geo.M * geo.F * np.tan(th / 2))))   # 5.3e-15
A_code, A_exact = 1 / (r1 + r2), np.cos(th / 2) ** 2 / (geo.M * geo.F)
rel = 20 * np.log10(A_code / A_exact); rel -= rel[0]
print(rel[-1])                                                   # -1.68 dB
```

## 2. [高] 复口径场被截成实部，变形相位整段丢失

**位置**：`src/go_po/po.py:76`（`np.asarray(illumination(rho), dtype=float)`）

**问题**：`far_field_aperture` 只能吃实幅度。传复口径场（本项目「变形→相位」的核心输入）时，
numpy 只发一条 `ComplexWarning` 就取实部，静默算错。

**依据**：远场积分的基本输入是复场 `|E_a|e^{jΔφ}`；这里只留 `Re(E_a)`。
平滑变形（如 defocus `φ = 10(r/R)²`）被换成 `cos(10(r/R)²)`，不再有任何相位倾斜。

**实测**：截断版第一零点 1.76°（正确 3.50°）；3.2°/4.8°/8° 处比正确值高 7.2/7.6/10.6 dB，
8° 处甚至比视轴高 6 dB。

**陷阱**：对高斯随机相位屏（σ=1 rad），视轴幅度碰巧等于 `E[cos φ] = e^{-σ²/2}`，
与正确的相干因子数值相同，所以拿随机屏做校验会「看起来对」。

**验证**：

```python
from go_po.po import far_field_aperture
far_field_aperture(10, 2*np.pi,
    lambda r: np.exp(1j*10*(r/10)**2), np.array([0.0, np.radians(5.0)]))
# ComplexWarning + 完全错误的方向图；dtype 改 complex 即恢复
```

## 4. [中] `Cassegrain.half_angle_feed` 不是馈源照射半张角

`src/common/cassegrain.py:100–103`，打印在 `summary():277` 的「馈源半张角」。

它算 `atan(R/(z_rim − z_far)) = 72.65°`，那是馈源到主面边缘的直线张角。
卡塞格伦的边缘射线必须先打副面，真正的馈源出射角是 17.76°。

`feed_half_angle_for_edge(geo)` 实测 17.7613°，`trace_rays` 的 `theta.max() = 17.02°`。
若拿 72.65° 去算边缘锥削，`cos⁴(72.65°) = −42.0 dB`（不是 −1.70 dB）。

验证：`np.degrees(geo.half_angle_feed)` vs `np.degrees(feed_half_angle_for_edge(geo))` → 72.646 / 17.761。

## 5. [中] 测试：一批恒真式断言，核心模块零覆盖

- `test_boresight_is_normalised`：返回值恒等于 1（θ=0 时分子分母都是 `Σamp dA`）
- `test_pipeline_is_reproducible`：纯确定性函数，两次必然相同
- `test_rays_land_within_aperture`：`theta_max` 是用同一个追踪器二分出来的，采样又取中点，
  最外圈只落到 9.577λ（余量 0.42λ），根本没碰到边缘
- `test_geometry` 的近焦点/F 与 M 恒等式可由 `a=(M−1)(F−L)/2, c=(M+1)(F−L)/2` 直接推出，
  验的是「公式和属性一致」，不是「公式是卡塞格伦共焦条件」
- 没有任何测试引用 `go_po.aperture_po`、`go_po.feed` 或 `po_surface_far_field`，
  而 validate_po 的 L1/L2/L3 全靠 aperture_po
- `validate_po` 的退出码只看 `l1_ok`，L2/L3 失败不会让脚本失败

物理判据应是「数值 vs 解析/极限」，不是「函数返回自己定义的值」。
验证：把 `trace_rays` 的 `theta_max` 改成 `0.5*edge` 再跑 `test_rays_land_within_aperture` 依旧通过。

## 6. [中低] `far_field_pattern` 峰值归一化把增益损失恒等抹成 0 dB

`aperture_po.py:158–161`：`peak = max|field|; return |field|/peak`，最大值恒为 1.0。
而 `tapered_aperture(phase_error=...)` 是唯一能带复相位的口径场工厂，只能喂给这个函数，
于是「变形→增益下降」永远算不出来。

G/G0 是轴向场模之比，峰值归一化正好把它除掉。validate_po 注释（:127–128）已承认并绕开，
但 API 没改。修法：照 `far_field_aperture` 加显式 `normalize` 参数，或另给 `on_axis_field()`。

## 7. [低·存疑] 馈源 cos^q 没有功率归一化

`feed.py:15–28`：只给相对形状，没有 `∫|g|²dΩ = 1`（或 4π）。
cos^q 功率图的全空间积分是 `2π/(q+1)`，q=8 时为 0.698，不是 1；对应方向性 `2(q+1) = 12.55 dBi`。

当前所有结果都是相对值，尺度被归一化消掉，**不影响现有数字**。
但论文若要写馈源增益/口径效率，这个 feed 不能直接给 dB。

## 8. [低] 口径远场积分不带斜度因子

`po.py:53–91` 是标量 Kirchhoff，没有 `(1+cosθ)/2`；`aperture_po.far_field_pattern` 有。
同一口径经两条「PO」通路会给出不同副瓣。

本例到 10° 只差 `20log10((1+cos10°)/2) = −0.066 dB`（第一副瓣 0.015 dB），可忽略；
但 60° 处差 2.5 dB，若论文讲大角度/后瓣或换深抛物面，误差会长大。

## 9. [低] 表面 PO 的归一化点不是视轴，且丢掉了 jk/(4πr)

`po.py:156–166`：`ref = np.abs(e_far[0]).max()` 用「传进来的第一个 θ」当参考，`theta[0]≠0` 时不可比；

## 查过、没发现问题的部分

- **射线追踪**：副面/主面法向取「朝来波侧」正确，`_reflect` 正确，准直 4.4e-16、光程起伏 7.1e-15。
  `path_length_ripple` 的定义：`r1+r2−z_main = F+2a = 12.8`，与代码一致，不是凑出来的常数。
- **卡塞格伦几何**：近焦点=F、`M=(c+a)/(c−a)`、副面边缘用「F–副面边缘–主面边缘三点共线」求根，都对；
  `blocking_ratio=(d_rim/D)²` 作为沿 z 剪影的面积比成立；`with_blockage` 二分方向正确。
- **表面 PO 公式**：`J=2n×H`、`H=(1/η)r̂×E`、相位 `exp(+jk r̂·r′)`、横向投影 `(I−rrᵀ)`、
  面元 `dS=dA·sqrt(1+(dz/dρ)²)` 都对。与口径 Kirchhoff 积分对打，主瓣/副瓣区一致到 0.01–0.6 dB。
- **数值积分**：Airy 偏差 1.4e-5 / 7e-6；200×320 网格径向相位步长 0.05 rad、方位向 ~29 样本/周期，
  无混叠；表面 PO 140×240 对 280×480 只在深零点差 0.46 dB。
- **单位**：全链路 λ 归一化，`k=2π` 三处一致；`ETA0` 只作比例因子。
  `Cassegrain.lam` 是遗留字段，不算错但容易误导。
